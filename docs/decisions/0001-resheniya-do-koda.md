## Платформа
- Python ≥ 3.11 — требование `polymarket-client` 0.10.0 (PyPI, 19.09.2026).
  Проверяется матрицей CI. Локально Python 3.14.7, uv 0.12.3, Docker 29.7.2.
- SDK `polymarket-client` 0.10.0, MIT. Методы, нужные проекту, есть в
  `PublicClient` (проверено установкой в scratch-окружение 19.09.2026):
  `list_markets`, `search`, `get_order_book(s)`, `get_midpoint(s)`, `get_spread(s)`,
  `list_trades`, `list_price_history`, `list_market_rewards`, `subscribe` (WebSocket).
- Ограничения площадки (SOURCES.md):
  - минимальный ордер 5 акций и тик 0.01 приходят в стакане (`prices-order-books.md`);
    не зашивать, читать из ответа;
  - комиссия считается по `feeSchedule` рынка: `rate`, `exponent`, `takerOnly`,
    `rebateRate` (`market-details.md`); формула `C × rate × p × (1 − p)` при
    exponent = 1 (`fees.md`); округление до 5 знаков; мейкер не платит;
  - Data API отдаёт 429 с `Retry-After` при превышении квоты — клиент обязан
    ждать указанное время (`data-api-openapi.json`);
  - история цен: минутная — не менее 7 дней, 5-минутная — 60, 30-минутная — 90,
    3- и 12-часовая — с 2022-11-18; окно start/end ≤ 15 дней за запрос;
  - история сделок `/v2/trades`: по condition до 3 лет, limit ≤ 1000, cursor;
  - истории стакана нет — стакан записывается самим инструментом через WebSocket;
  - движок может входить в post-only режим с `Retry-After` (`matching-engine.md`).
- Что требует аккаунта, подписи или денег: ничего в объёме проекта. Публичные
  эндпоинты работают без ключа (`data-api-openapi.json`: «no API key required»;
  `api-overview.md`: public market data requires no credentials).
  Live-режим требовал бы кошелёк на Polygon и pUSD — вне объёма (см. ниже).

## Дополнение 19.09.2026 — условия использования прочитаны
Источник: Polymarket.com Terms of Use, «Effective as of August 11, 2026», Google Doc,
встроенный в polymarket.com/tos (читался через мобильную версию документа из Узбекистана).
- Принятие: «BY ACCESSING … (INCLUDING BY CONNECTING VIA AN API …) YOU AGREE …» — работа
  через API означает принятие условий.
- Ограниченные территории: список в тексте (США, ЕС-страны, Великобритания, Россия, Сингапур
  и др.) и по ссылке `https://docs.polymarket.com/api-reference/geoblock`. Узбекистана нет.
  VPN для обхода запрещён, «THERE ARE NO EXCEPTIONS».
- Лимиты: «use … may be subject to … transaction limits or rate limits», меняются без
  уведомления → клиент уважает 429/Retry-After и не превышает документированные квоты.
- Запрещённое поведение (раздел Prohibited Conduct), важное для нас:
  - «Use any data mining tools, robots, crawlers, or similar data gathering and extraction
    tools to scrape or otherwise remove data from the Site» — инструмент не ходит на сайт,
    только в документированные API; «the Company reserves the right to grant access to
    public on-chain infrastructure and the Company's builder program».
  - «Harvest or otherwise collect information … for any unauthorized purpose» — цель:
    симуляция и исследование на публичных данных; трактовка как разрешённой — наша,
    юристом не подтверждена, помечено.
  - Ограничение на Data для «Capital Market Client» и «market data distributor» и запрет
    перепродажи данных — к владельцу не относится; в README: данные не перепродаются.
  - Wash trading, spoofing, front-running, фиктивные сделки — запрещены. В paper-режиме
    ордеров нет; в документации стратегий это ограничение записано для любого, кто
    возьмёт код в live.
- Право Панамы, арбитраж. Не влияет на архитектуру.
Вывод: использование публичных API в paper-режиме условиям не противоречит при
уважении лимитов; live-режим по-прежнему вне объёма (право Узбекистана).
