# 0004 — Kalshi: адаптер данных не делаем

Дата: 2026-09-19. Владелец решений: владелец проекта; это справка, не юридическая консультация.

## Что прочитано
- **Kalshi Developer Agreement v1.1** (kalshi-public-docs.s3.amazonaws.com/Kalshi-Developer-Agreement.pdf,
  6 страниц). П. 1: любое обращение к API означает принятие. П. 3: «Use of Kalshi APIs is
  expressly limited to facilitating a members own trading on the Exchange; all other usages
  are disallowed». П. 3.1: запрет «collecting, caching, aggregating, or storing data … except
  for purposes of facilitating your own trading», запрет передачи третьим лицам без
  письменного разрешения. П. 4.1.1: пользователь API обязан быть участником биржи.
  П. 6.4: публичные заявления и материалы, касающиеся API Kalshi, требуют
  предварительного письменного одобрения.
- **Kalshi Data Terms of Use** (kalshi-data-terms-of-service.pdf, 3 страницы): данные сайта
  только для личного некоммерческого использования; без письменного согласия запрещены
  разработка любого ПО на этих данных, архивы и кэши, оценочные сервисы и управление
  риском, любое использование в связи с ИИ.
- Документация docs.kalshi.com: публичные REST-эндпоинты рыночных данных без ключа
  существуют; WebSocket требует аутентификации. Серия KXBTC15M — 15-минутные рынки по
  BTC с тем же окном и тем же правилом («среднее 60 с индекса в конце ≥ среднему в начале»),
  что у Polymarket, но по индексу CF Benchmarks BRTI, а не Chainlink.

## Решение
Адаптер данных Kalshi, запись и хранение их стакана и сделок в paperfill не делаются:
владелец не участник биржи (резидентам вне США участие недоступно), хранение данных
вне собственной торговли запрещено, публичный репозиторий с кодом под API Kalshi
потребовал бы письменного одобрения. Документация Kalshi в локальном хранилище
источников остаётся: это документация, а не данные.

Что сделано вместо: (1) интерфейс площадки `venues.py`, через который заказчик-участник
подключает свои лицензированные данные, с единственной реализацией Polymarket;
(2) детектор пар `pairs.py` на данных Polymarket: моменты, когда сумма лучших ask по Up
и Down меньше доллара после комиссий тейкера, то есть безрисковая покупка пары.

## Факт для честности
До прочтения соглашения для проверки доступности было сделано около десяти
неаутентифицированных GET-запросов к публичным эндпоинтам (рынки, стакан, сделки, серии).
Данные не сохранялись и не использовались. Больше запросов к API Kalshi проект не делает.
