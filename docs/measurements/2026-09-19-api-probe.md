# Замер 2026-09-19: публичный API Polymarket через polymarket-client 0.10.0

Окружение: scratch venv, Python 3.11, без ключа, из Ташкента. Наблюдалось, не «должно».

- `PublicClient().list_markets(condition_ids=[cid])` → `Paginator`; `.first_page().items[0]`
  — модель `Market` с полями `state` (active, closed, accepting_orders, neg_risk, start_date,
  end_date), `outcomes` (`yes`/`no` → label, token_id, price), `trading`
  (minimum_order_size "5", minimum_tick_size "0.01", fees_enabled, fee_type
  "crypto_fees_v2", fee_schedule {exponent 1, rate "0.07", taker_only true, rebate_rate "0.2"}),
  `resolution` (source: Chainlink BTC/USD TWAP 60s stream), `rewards`
  (rewards_min_size "50", rewards_max_spread 4.5), `metrics`, `prices`.
- Итерация по `Paginator` отдаёт объекты `Page`; элементы — через `.iter_items()`.
- `get_order_book(token_id=…)` за 0,40 с: `bids` и `asks` — списки {price, size} строками;
  лучшая цена стоит **последней** в каждом списке (bids по возрастанию, asks по убыванию).
  Поля `min_order_size`, `tick_size`, `neg_risk`, `hash`, `timestamp`.
- `list_trades(condition_id=…)` → `Trade`: wallet, asset_id, side, size, price, timestamp
  (ISO, секунды), transaction_hash, outcome. Для закрытого 5-минутного рынка BTC от
  2 апреля 2026 отдано 5 347 сделок одним проходом с page_size=1000.
- `list_price_history(asset_id=…, interval="1h", bucket_seconds=60)` → точки
  {timestamp UTC, price Decimal, resolution_seconds 60}.
- Открытых рынков «X Up or Down» на 5 минут одновременно ≥ 8 (BTC, ETH, SOL, XRP, BNB,
  DOGE, ZEC, HYPE), закрытие каждые 5 минут.
- Gamma REST без SDK: `/markets?closed=false&order=endDate&ascending=true&end_date_min=…`
  отдаёт те же `feeSchedule`; `/public-search?q=…` находит только закрытые события по
  свободному тексту — для поиска живых рынков использовать `/markets` с фильтрами.
