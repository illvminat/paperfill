# Замер 2026-09-19: комиссии сквозь весь конвейер

Разбор 0003 отметил, что образцы-стратегии post-only и движок комиссий не проверен
сквозным прогоном. Для этого добавлена стратегия `taker-probe`: раз в 30 с покупает по 5
акций обоих токенов по лучшему ask (FAK). Не торговая идея, а зонд.

Запись окна 22:45–22:50 UTC (та же, что в замере I2), капитал 100.

| Показатель | Значение |
|---|---|
| Ордера / исполнения (все тейкер) | 20 / 20 |
| Комиссии по отчёту | 1,70392 |
| Комиссии, пересчитанные из журнала по `C × 0,07 × p × (1 − p)` с округлением HALF_UP до 5 знаков | 1,70392 |
| То же с округлением HALF_EVEN | 1,70382 (три исполнения по 0,50 и 0,51 попадают на границу) |
| P&L после расчёта по исходу | −2,20392 |
| Изменение кассы 100 → 97,79608 | −2,20392, равно P&L |
| Сумма P&L по токенам из отчёта | −2,20392, равна P&L (после правки отчёта) |

Что подтверждено: комиссии считаются по формуле рынка на каждом исполнении, входят в
базис позиции и в реализованный P&L, и три числа (касса, реализованный P&L, сумма по
токенам) сходятся. Что осталось допущением: режим округления на пятом знаке;
документация его не называет, принят HALF_UP, разница на 20 сделках 0,0001.

Найдено по ходу: отчёт показывал P&L по токенам без комиссий и с четырьмя знаками,
поэтому не сходился с итогом; исправлено на шесть знаков USDC с комиссиями в базисе.
